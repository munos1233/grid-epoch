# 衍枢 GridEpoch：28 张竞赛截图

本目录共 28 张图片，按答辩顺序编号：前 21 张为 Safari 原生窗口值班台截图；后 7 张为用户在 macOS Terminal 截取并发送的真实命令行截图。

页眉显示本机更新状态，最终召回固件放在第 21 张。第 22—28 张按 `make bench`、`make test`、`make demo` 两步、`make split` 两步、五进程 `ps aux | grep grid_epoch` 排列。

第 1 张 Safari 页脚与同一轮 `make bench` 一致：100 万台确认重算 0.720 秒。`make bench` 中逐台 SM2 本机估算和仓库参考分别标注。
