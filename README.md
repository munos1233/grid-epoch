# 衍枢 GridEpoch

面向千万级配电终端的分级派生与纪元广播密钥管理方案。对应赛题 **A1-6 电力领域海量配电终端批量密钥管理方案设计实现**。业务加密用 SM4，杂凑和派生用 SM3，纪元报文只带 SM2 协同签名。接入认证用 SM9 标识签名，不进入百万台更新。更新确认用业务密钥标签，台区收成固定长度后由主站重算。

省级软件密码模块保存两把主密钥、SM9 签名主私钥、协同签名的调用方分片，以及广播树根。它不是硬件密码机。地市只拿到本节点的广播密钥、管控委托密钥、业务委托密钥和一张范围令牌，推不出兄弟地市。县再向下拿自己的两把密钥。终端树 `2^28`，每台区 2048 个槽，10 万台区，网关树 `2^19`（每台区 4 个槽，不复用）。省级广播根下有 65536 个等长地市槽。叶子按台区区间单调分配，用过不再回收。空吊销是一条根密文；整批、整区、整县各是一条子集差密文；散点坏表也走子集差。终端报文只带一条覆盖密文和 Merkle 证明。认证随机数给台区，业务随机数只进终端覆盖。仍在覆盖集里的终端可以跳过中间纪元。被吊销的终端拿不到新随机数。

| 赛题要求 | 本方案 |
| --- | --- |
| 不少于 1000 万台终端的密钥管理 | 终端树 `2^28`，每台区 2048 槽，按 10 万台区使用；种子流式派生，不落库。基准这一次在每个台区派生 100 台，共 1000 万台 |
| 密钥层级不少于 2 级，支持分级认证加密 | 省—台区—终端三级；台区能认证，解不开业务明文 |
| 不少于百万级终端并行密钥更新 | 100 万台终端处理同一份广播；确认按台区收成 62 字节，主站流式重算 |

现行说明见 [docs/方案设计.md](docs/方案设计.md)，现场顺序见 [docs/现场演示.md](docs/现场演示.md)。[docs/优化方案.md](docs/优化方案.md) 和 [docs/第二轮优化.md](docs/第二轮优化.md) 是修订档案。

## 运行

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
make demo
make test
make bench
```

`make demo` 走通灌装、激活、分级认证加密、离线直达、吊销、确认核验和换表。`make test` 核对 SM3/SM4 标准测试向量、派生一致性、逻辑密钥树、纪元跳转和吊销。`make bench` 实测规模。

## 这台机器上的实测

Apple Silicon，macOS arm64，10 线程。换机器后以 `make bench` 的输出为准，结果写在 `bench/last_result.json`。

| 项目 | 结果 |
| --- | --- |
| 1000 万台种子派生 | 0.668 秒，约 1498 万台/秒 |
| 100 万台对称更新模拟 | 1.462 秒，约 68 万台/秒 |
| 100 万台确认重算 | 0.756 秒，约 132 万台/秒，完成帧 62 字节 |
| 1000 万台确认重算 | 7.926 秒，约 126 万台/秒 |
| 本机 4 进程扇出派生 100 万台 | 0.219 秒，约 456 万台/秒，不是地市广域网 |
| 无吊销时的终端报文 | 236 字节；网关 216 字节；吊销根 118 字节 |
| 1000 条覆盖时的终端切片 | 545 字节 |
| 省级一次组包 | 38.1 毫秒，含 3 次 SM2 协同签名和这一纪元的门限托管 |
| 单份终端报文 SM2 验签 | 6.32 毫秒 |
| 逐台 SM2 加密下发 100 万把密钥 | 单次 6.4 毫秒，合计约 1.8 小时 |

百万台循环里，每台终端打开同一条 36 字节明文的 SM4 密文，再沿业务种子和认证种子两棵时间树走到纪元叶子，派生认证密钥和业务密钥。验签单独计时，不放进这 100 万次。1.462 秒是主机把这些对称计算叠在一起的墙钟，不是一台终端的换代时间。一台终端本地大约是 6.32 毫秒 SM2 验签加 14.6 微秒对称计算。主站对整个簇只组一次包。确认重算是另一段流式计算：主站按业务种子和业务随机数重算 16 字节标签并异或，不把标签落库。到齐的台区上行是 62 字节。无吊销时覆盖种类是完全子树，终端报文仍是一条根密文。吊销根里的 32 字节是 Merkle 根，其余字节是 SM2 签名套件。整区、整县、整批各收成一条子集差密文。终端只收一条，是因为纪元头上的 Merkle 抽取。4 进程扇出是本机上的另一段派生，不替换上面的单进程数字。

## 代码地图

| 路径 | 内容 |
| --- | --- |
| `grid_epoch/derive.py` | 密钥派生的字节布局，评审对公式时看这里 |
| `grid_epoch/ack.py` | 完成帧、差额帧和明细帧 |
| `grid_epoch/sdkey.py` | 子集差标签，不经过 NODE 路径密钥 |
| `grid_epoch/sm9id.py` | 接入认证的 SM9 标识签名 |
| `grid_epoch/tree.py` | 逻辑密钥树的覆盖集 |
| `grid_epoch/subtree.py` | 按台区区间单调分配的长期子集密钥 |
| `grid_epoch/package.py` | 纪元头签名、覆盖条目 Merkle、终端切片 |
| `grid_epoch/city.py` | 地市委托密钥、注册、吊销和组包 |
| `grid_epoch/city_server.py` | 地市进程。不打开灌装包，也不装入省级主密钥 |
| `grid_epoch/factory.py` | 产线进程。设备私钥和种子只在这里打开 |
| `grid_epoch/custodian.py` | 保管进程。只接收第三份分片，不接收口令 |
| `grid_epoch/session.py` | 值班台用来连接地市进程和产线进程 |
| `grid_epoch/desk.py` | 值班台操作：发布、吊销、销毁、归档、召回 |
| `grid_epoch/services.py` | GE01 电能量和 GE03 控制 |
| `grid_epoch/device.py` | 终端 SM2 灌装封装 |
| `grid_epoch/console.py` | 本机值班台页面，`python -m grid_epoch.console` |
| `grid_epoch/split_demo.py` | 主站与终端分进程的三步演示 |
| `grid_epoch/kmc.py` | 省级软件模块边界、纪元签名、确认核验 |
| `grid_epoch/terminal.py` | 终端与台区网关 |
| `native/` | SM3、SM4 和批量派生 |
| `docs/方案设计.md` | 现行说明 |
| `docs/现场演示.md` | 五分钟现场顺序 |
